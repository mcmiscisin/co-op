How to play
  1. Enter whole-number coefficients (use 1 for “no change”).
  2. Press Enter or click Check.
  3. Hint shows atom counts LHS vs RHS so you can nudge toward balance.
  4. On the scale, one colored sphere = one atom. A white outline marks an unmatched atom.
  5. Show answer reveals one valid balanced set.
Why this matters

Balancing enforces the Law of Conservation of Mass—atoms aren’t created or destroyed. You’re matching the number of each atom on both sides.

Great practice for stoichiometry and for spotting polyatomic groups that carry through reactions.

Visual key: each sphere is one atom. Matching colors should have matching counts on both sides. The scale turns green only when every element is conserved.

Each colored sphere represents exactly one atom. Unmatched atoms have a bright white outline. The beam levels and turns green only when every element has the same count on both sides.
